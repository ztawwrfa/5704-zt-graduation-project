# 题目确认

## 题目全称
面向嵌入式边缘设备的轻量化目标检测模型优化与部署研究

## 研究问题（一句话）
如何在嵌入式边缘设备上，通过轻量化方法在可接受的精度损失内显著降低目标检测模型的参数量、模型大小与推理延迟，并完成实际部署验证。

## 研究方向
轻量化目标检测 / 边缘智能

## 研究边界
### 做什么
- 选定一个具体检测场景与数据集
- 建立标准 Baseline
- 实现至少一种轻量化方法（量化/剪枝/轻量骨干/结构优化）
- 部署到真实边缘设备
- 统一指标对比与消融实验

### 不做什么
- 不追求在服务器 GPU 上刷 SOTA
- 不涉及多节点协同（属于拓展目标）
- 不做与部署无关的纯理论分析

## 预期成果
- 一套可复现的轻量化检测模型与部署流程
- 完整的精度—效率对比结果
- 毕业论文与实验报告
