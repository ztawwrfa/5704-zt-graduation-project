# 技术路线

## 阶段 1：场景与数据确定
- 输入：候选检测场景、公开数据集
- 方法：调研并选定具体场景与数据集，明确类别与评价协议
- 输出：场景说明 + 数据集版本 + 评价指标定义

## 阶段 2：Baseline 建立
- 输入：选定数据集
- 方法：选用一个标准检测模型（如 YOLO 系列）跑通训练与评估
- 输出：第一组可复现 Baseline 指标（mAP/Precision/Recall/参数量/延迟）

## 阶段 3：轻量化方法实现
- 输入：Baseline 模型
- 方法：至少一种轻量化手段（量化 / 剪枝 / 轻量骨干 / 结构优化），明确目的
- 输出：轻量化模型 + 初步对比结果

## 阶段 4：边缘设备部署
- 输入：轻量化模型
- 方法：转换并部署到目标边缘设备（如 Jetson / 树莓派 / 手机等）
- 输出：设备端推理延迟/FPS、内存或功耗实测

## 阶段 5：实验与消融
- 输入：Baseline、轻量化模型、部署结果
- 方法：统一指标对比 + 消融/参数实验 + 失败案例分析
- 输出：完整实验表格与结论

## 阶段 6（拓展）
- 多节点协同 / 进一步剪枝量化 / 强化学习任务调度
- 输入输出：视具体拓展方向而定
